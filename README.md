# No-Bullshit Feminist Test（NBFT）

**尊重女性的主体性，让女性作为具体的人存在。**

NBFT 是主要面向广告行业的女性主义审稿 Skill，适用于广告文案、故事和视频脚本。它结合具体叙事语境判断，不放过贬低和物化，也不要求每支广告机械补齐角色。

**“No-Bullshit”反对的是空洞姿态、机械打勾和缺乏依据的判断。**

## 它审查什么？

- 整体表达是否贬低女性。
- 人物是否被性别模板限制，能否保有自身的处境、需要和选择。
- 适用的群像作品中，是否有可辨识的女性及有内容、体现主体性的交流。

讨论男性不自动失败；只有男性的故事也不自动失败。第三项是否适用或豁免，要看具体叙事理由。第一、第二项始终检查。

## 怎么使用？

将技能文件夹命名为 `nbft`，按所用工具的方式安装或导入。

**创作与审查请使用不同会话：**

1. 新建审查会话，提交作品和必要背景，明确要求“请用 NBFT 审查”；支持技能标识的工具也可使用 `$nbft`。
2. 回到创作会话修改，再将修订稿交回审查会话复审。

若当前会话参与过作品创作或改写，NBFT 会停止出具结论，生成交接文件，供新会话审查。分开会话有助于减少先前创作思路的影响，但不保证绝对客观。

## 会得到什么？

结论为“通过”或“需修改”，附适用情况、具体依据和修改要求。关键材料不足时，说明待补信息，不默认通过。

NBFT 只负责审查，不提供改写成稿或替代文案。修改由创作者或其他创作 Skill 执行，修订后重新审查。
