# No-Bullshit Feminist Test（NBFT）

**尊重女性的主体性，让女性作为具体的人存在。**

NBFT 是面向广告创作者的女性主义审查 Skill，适用于文案、海报、图像、故事和视频。它检查女性的处境、感受、愿望与选择是否真正重要，提供判断依据和修改要求。

“No-Bullshit”反对空洞姿态、机械打勾和缺乏依据的判断。

## 检查什么？

1. 整体表达是否贬低女性。
2. 人物是否保留与篇幅和作用相称的复杂性。
3. 适用的群像中，女性是否存在，并有体现自身需要的实质交流。
4. 女性身体是否被缩减为吸引观看或促销的工具。

判断也看镜头、情绪和结局在赞美什么。作品没有直说女性应该牺牲或取悦别人，仍可能传递这种标准；但女性付出、性感、谈论男性，也不自动构成问题。

## 得到什么？

| 结论 | 含义 |
| --- | --- |
| 🟢没问题 | 在审查范围内，所有适用项符合标准。 |
| 🔴有风险 | 已有充分依据确认问题，需要修改。 |
| 🟡有疑点 | 有具体表达疑点或关键证据缺口，需要进一步判断。 |
| ⭐案例级 | 绿灯之上的推荐：对理解女性处境或拓展表达有突出贡献。 |

有红则红，无红有黄则黄。星标显示为“🟢没问题 · ⭐案例级”。每次结论附材料范围、评价依据和必要的修改要求或待补信息。

## 怎么用？

1. 将 `nbft` 文件夹按所用工具的方式安装或导入。
2. 在独立审查会话提交作品及必要背景，明确说“请用 NBFT 审查”，或使用 `$nbft`。
3. 回到创作会话修改，再提交实际修订稿复审。

NBFT 只在明确调用时运行，只审查、不代写。若当前会话参与过该作品创作，会生成交接材料供新会话审查。会话分离有助于减少创作惯性，不保证绝对客观。
